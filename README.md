# Trial Entry PWA

Offline data entry for swine trials (sow feed per meal, litter, farrowing, piglets, body condition).
Entries are queued on the device and sent to the trial's Google Sheet through an Apps Script web app.
Endpoint URL, trial code and personal access code are entered on each device; nothing secret is stored in this repo.

Release: bump `SHELL` in `sw.js`, commit, push. Installed apps show "New version" and update on tap.
